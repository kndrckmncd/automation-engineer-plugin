# IDP Framework — SMART Goals & Automation Engineer Competencies

## The SMART Goal Framework

Every IDP goal must satisfy all five criteria:

| Criterion | Question to Ask | Weak Example | Strong Example |
|-----------|----------------|--------------|----------------|
| **Specific** | What exactly will be done? | "Be involved in chatbot" | "Lead development of the Jira automation skill for the Copilot CLI plugin" |
| **Measurable** | How will success be verified? | "Do some training" | "Obtain UiPath Advanced Developer certification" |
| **Achievable** | Is it realistic given capacity? | "Build 10 bots" | "Deploy 1 production-ready AI-integrated bot" |
| **Relevant** | Does it align with role/team goals? | "Learn cooking" | "Complete AI/ML fundamentals to support AI-integrated RPA initiatives" |
| **Time-bound** | When will it be done? | "TBA" | "Q3 2026 (by September 30)" |

## Manulife Automation Engineer Competency Areas

Use these to populate the **Development Areas** section of the IDP.

### Technical Competencies

| Competency | Developing | Proficient | Advanced |
|------------|-----------|-----------|---------|
| RPA Development (UiPath/Power Automate) | Builds basic attended bots | Builds complex unattended production bots | Designs bot architecture, mentors others |
| AI/ML Integration | Aware of concepts | Integrates LLM APIs in bots | Designs AI-driven automation solutions |
| API & System Integration | REST API basics | Complex multi-system integrations | Designs integration patterns |
| Process Analysis & SDD | Documents current state | Writes detailed SDDs with swimlanes | Leads process discovery workshops |
| Testing & QA | Manual testing | Automated test scripts | End-to-end test framework design |
| DevOps & Git | Basic git commits | Branching, PRs, CI/CD pipelines | Designs deployment pipelines |

### Professional Competencies

| Competency | Developing | Proficient | Advanced |
|------------|-----------|-----------|---------|
| Communication | Presents to team | Presents to stakeholders | Executive-level communication |
| Problem Solving | Resolves known issues | Diagnoses novel issues independently | Leads complex cross-team problem resolution |
| Documentation | Basic process notes | Full SDDs and runbooks | Standards-setting documentation |
| Mentoring / Knowledge Sharing | Shares tips with peers | Conducts training sessions | Builds team capability programs |

## Goal Category Definitions

| Category | When to Use |
|----------|------------|
| **Technical** | Hard skills: RPA tools, AI/ML, APIs, coding, testing |
| **Process** | Automation delivery, SDD writing, deployment, production support |
| **Leadership** | Stakeholder management, presenting, mentoring, leading initiatives |
| **Growth** | Certifications, training, industry knowledge, personal development |

## Status Values

| Status | Meaning |
|--------|---------|
| Not Started | Goal identified but no action taken yet |
| In Progress | Active work underway |
| Completed | Deliverable achieved and verified |
| On Hold | Paused due to external factors |
| At Risk | Progress behind schedule |

## Recommended Goals for Automation Engineers at Manulife (2026)

Use these as inspiration when generating goals:

1. **Technical** — Complete one end-to-end automation project using AI/LLM integration (e.g., GitHub Models API, Azure OpenAI) deployed to production
2. **Technical** — Obtain or renew UiPath certification (Associate, Developer, or Advanced Developer)
3. **Process** — Own the full SDD lifecycle for at least one automation project (As-Is diagram → Future State → handover)
4. **Leadership** — Present automation POC or tool to team/stakeholder audience at least once
5. **Growth** — Complete one approved external training course (technical or leadership track)
6. **Process** — Contribute to at least one team knowledge-sharing session (runbook, wiki, or demo)
